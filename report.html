CSY1063 AS1 Website Development Report

This report reflects on the development of the GetSauced website, covering learning experiences, design decisions, challenges faced, and technical implementations.

Learning Reflections

Developing this website has been an invaluable learning experience in web development fundamentals, especially because i want to use this skill to help me build my website for my own company. Over the course of Weeks 1-6, I gained a solid understanding of HTML, ensuring proper structure with elements like header, nav, main, section, and footer. This not only improves accessibility but also makes the code more maintainable. CSS has been helpful also, with the use of variables for consistent theming, Grid for complex layouts, and responsive clean design techniques. JavaScript interactions, such as the hamburger menu, added functionality that enhances user experience on mobile devices catering to all users on the site. The project reinforced the importance of validation, both for HTML and CSS, to ensure cross-browser compatibility and adherence to web standards.

Design Decisions

The design was chosen to reflect my luxury item sourcing brand, with a modern dark theme using black, white, and gold colors. Serif fonts were selected for headings to convey elegance, while sans-serif for body text ensures readability. The layout uses CSS Grid on the projects page to create a distinct visual from other pages, showcasing different grid implementations. Responsive design was prioritized, with breakpoints for mobile, tablet, and desktop to ensure usability across devices.

Debugging and Challenges

Several challenges arose during development. Implementing the hamburger navigation required me to research alot of JavaScript handling to toggle classes and ensure smooth transitions. CSS Grid initially caused issues with alignment, but using grid-template-areas resolved this. Form validation in the contact page needed attention to ensure proper mailto functionality. Debugging involved using browser dev tools extensively, checking for console errors, and validating code regularly to catch issues early.

Font and Colour Choices

Colors: Black (#000000) for backgrounds, white (#FFFFFF) for text, gold (#D4AF37) for accents. Fonts: Serif like 'Times New Roman' for headings, sans-serif like 'Arial' for body. These choices create a luxurious, professional appearance suitable for a high-end brand.

Influences

The design was influenced by other luxury watch and sneaker brand websites i researched and analysed, such as Rolex and Nike official sites, which emphasize clean layouts and high-quality imagery. Modern web design trends from sites like Apple's product pages inspired the hero sections and call-to-action buttons.
